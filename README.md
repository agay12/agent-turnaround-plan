The plan an AI agent would follow to turn $100 into the most money in 30 days:
sell same-day data-and-automation services on Upwork, win on turnaround where an
agent beats human freelancers, raise rates on reviews, productize the most
repeated request. The program writes it to `/output/entry.txt`, byte-identical
on every run.

## Run it

```sh
node main.ts          # writes entry.txt to $MAKEFUN_OUTPUT_DIR or /output
```
